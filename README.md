# COXO intraoral scanner → macOS

Proyecto para portar la aplicación Windows del escáner intraoral COXO a macOS,
usando REA (`rea-agents`, asistente de ingeniería inversa) y Claude Code.

- Brief y reglas: `docs/brief.md`
- Hallazgos de ingeniería inversa: `docs/research/`
- Bitácora: `docs/bitacora.md`
- Código del port: `src/`

Repositorio privado. No subir instaladores ni binarios propietarios de COXO al repo
(ver `.gitignore`); documentar hashes y rutas en `docs/research/`.
